# 무순 키우기 관찰기 웹앱 — 설치/배포 가이드

이 폴더의 파일들은 **구글 앱스 스크립트(Google Apps Script)** 로 만든 웹앱입니다.
별도의 서버나 호스팅 비용 없이, 선생님의 구글 계정만으로 무료로 만들고 배포할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 로직 (로그인, 학생 등록, 기록 저장/조회, 구글 시트·드라이브 자동 생성) |
| `Login.html` | 첫 화면 — 학생/교사 로그인, 교사 회원가입 |
| `Student.html` | 학생용 화면 — 오늘의 기록 작성, 나의 기록, 같은 반 기록 |
| `Teacher.html` | 교사용 화면 — 학생 등록, 오늘 제출 현황, 구글 시트 바로가기 |
| `Stylesheet.html` | 공통 스타일(디자인) |
| `SharedScript.html` | 공통 자바스크립트(로그인 세션, 사진 압축 등) |

## 1. 처음 설치하기 (최초 1회, 대표 선생님 1명만 하면 됩니다)

1. 구글 드라이브에서 **새 스프레드시트**를 하나 만듭니다. (이름 예: `무순앱_마스터`)
2. 스프레드시트 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다.
3. Apps Script 편집기가 열리면, 기본으로 있는 `코드.gs`(또는 `Code.gs`) 파일 내용을 지우고, 이 폴더의 `Code.gs` 내용을 그대로 붙여넣습니다.
4. Apps Script 편집기 왼쪽의 **파일 추가(+) → HTML** 을 눌러서, 아래 5개 파일을 각각 **정확히 같은 이름**으로 만들고 내용을 붙여넣습니다. (확장자 `.html`은 자동으로 붙습니다)
   - `Login`
   - `Student`
   - `Teacher`
   - `Stylesheet`
   - `SharedScript`
5. 저장(Ctrl+S / Cmd+S)합니다.
6. 편집기 상단의 함수 선택 드롭다운에서 `initializeSpreadsheet` 를 선택하고 **실행(▶)** 버튼을 누릅니다.
   - 처음 실행하면 권한 승인 화면이 뜹니다. 본인 구글 계정으로 "고급" → "이동(안전하지 않음)" 을 눌러 승인해주세요. (본인이 만든 스크립트이므로 안전합니다.)
   - 완료되면 안내 메시지가 뜹니다.

## 2. 웹앱으로 배포하기

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포** 를 클릭합니다.
2. 유형에서 **웹 앱**을 선택합니다.
3. 설정을 아래와 같이 지정합니다.
   - **실행 계정**: 나 (Me)
   - **액세스 권한이 있는 사용자**: 링크가 있는 모든 사용자 (같은 학교 안에서만 링크를 공유하면 됩니다)
4. **배포**를 누르면 웹앱 URL이 생성됩니다. 이 주소를 선생님들과 학생들에게 공유하세요.
5. 이후 코드를 수정하면, **배포 → 배포 관리 → 수정(연필 아이콘) → 새 버전** 으로 다시 배포해야 변경 사항이 반영됩니다.

## 3. 처음 사용 시작하기

1. 배포된 주소로 접속 → **교사** 탭 → **교사 회원가입**
   - 회원가입하면 그 선생님만을 위한 구글 시트(`OOO의 무순 관찰 기록`)와 사진 폴더가 자동으로 만들어집니다.
2. 교사 화면에서 **학생 계정 개별 등록** 또는 **일괄 등록**으로 우리 반 학생들을 등록합니다.
3. 학생들은 배포된 같은 주소로 접속해 **학생** 탭에서 로그인 후 매일 기록을 남기면 됩니다.
4. 다른 학급 선생님도 같은 주소에서 **교사 회원가입**을 하면, 자신만의 구글 시트가 별도로 자동 생성되어 서로 독립적으로 운영됩니다.

## 확정된 정책 (기획안 기준)

- 관찰 기간: 별도 제한 없음 (교사가 종료 시점 판단)
- 하루 1회만 제출 가능 (사진 1장 + 텍스트 3항목, 각 최대 500자)
- 같은 반 학생끼리는 서로의 기록을 볼 수 있음
- 앱 내 피드백 기능 없음 (교사가 구글 시트 데이터를 클로드 등으로 분석해 피드백)
- 학생 계정은 교사가 사전 등록
- 구글 시트는 교사 1인당 1개 자동 생성
- 같은 학교 내부 배포 전제로 별도의 접근 제한(초대 코드, IP 제한 등)은 두지 않음

## 알아두어야 할 점 (한계 및 주의사항)

- **데이터 저장 위치**: 모든 교사의 기록 스프레드시트와 사진 폴더는 "1. 처음 설치하기"를 진행한 **대표 선생님 1명의 구글 드라이브** 안에 자동으로 생성됩니다 (앱이 그 계정 권한으로 동작하기 때문입니다). 다른 선생님들은 교사 화면의 "구글 시트 열기" 버튼으로 자신의 시트에 접속해 보고, 필요하면 본인 드라이브로 사본을 만들거나 공유 설정을 조정할 수 있습니다.
- **비밀번호 보안**: 학생 비밀번호는 간단한 해시로 저장되지만, 이 앱은 학교 내부용 소규모 도구를 목표로 만들어졌으며 은행 서비스 수준의 보안은 아닙니다. 실제 개인정보(주민번호 등 민감정보)는 입력하지 않도록 해주세요.
- **사진 공개 범위**: 학생 사진은 "링크가 있으면 볼 수 있음"으로 설정되어, URL을 아는 사람은 누구나 볼 수 있습니다. 외부에 URL이 노출되지 않도록 주의해주세요.
- **사진 용량**: 브라우저에서 자동으로 가로/세로 최대 1024px, JPEG 70% 품질로 압축한 뒤 업로드합니다. 원본 화질이 필요하다면 별도 조정이 필요합니다.
- **동시 사용자 수**: 무료 구글 계정 기준 Apps Script는 하루 실행 시간에 제한이 있습니다 (개인 계정 하루 약 6분/1회 실행, 총 실행 한도 별도). 한 학급 규모(20~30명, 하루 1회 제출)에서는 문제가 없지만, 여러 학교가 동시에 대규모로 사용한다면 별도 서버 구조로 전환이 필요할 수 있습니다.
- **탭 이동 시 로그인 유지**: 로그인 정보는 브라우저의 세션 저장소(sessionStorage)에 저장됩니다. 브라우저 탭을 닫으면 로그아웃되며, 다시 접속 시 재로그인이 필요합니다.

## 다음에 더 다듬으면 좋은 것들

- 학생/교사 비밀번호 찾기(재설정) 기능
- 교사가 특정 학생 기록을 앱에서 직접 삭제/수정
- 사진을 여러 장 첨부하거나, 기록 기간 통계(연속 기록일 수 등) 보여주기
